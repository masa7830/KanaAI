# KanaAI

KanaAIは、日常生活に寄り添うAIコンパニオンを目指して開発しているプロジェクトです。

一般的なLLMが「質問に対して回答する」ことを中心としているのに対し、KanaAIでは、ユーザーとの継続的な関係性や日常生活への自然な関わりを重視しています。

## KanaAIの特徴

* ユーザーの名前や設定を記憶し、継続した会話を行う
* 時間帯に応じて「おはよう」「おかえり」など自然な挨拶を行う
* 予定や生活情報をもとに、必要なタイミングで声をかける
* 将来的には天気・予定・位置情報などを利用した自発的な通知に対応
* Kana、Pomeなど複数のAIキャラクターとの会話を実現する
* 最終的には、ユーザーとAI同士が自然に会話できる複数人対話を目指す

## 既存のLLMとの違い

ChatGPTなどの汎用LLMは、幅広い質問への回答や文章生成を得意としています。

KanaAIではLLMそのものを開発するのではなく、LLMを利用しながら、

**「ユーザーの日常に継続的に存在するAI」**

を作ることを目的としています。

そのため、単発の質問応答だけでなく、

* 長期的な記憶
* キャラクターごとの人格
* 日常的な挨拶
* 予定との連携
* 状況に応じた自発的な声かけ
* 複数AIによる会話

といった機能を組み合わせていく予定です。

## 使用言語

* Python

## 現在実装している機能

* ユーザー名の入力
* ユーザー名を使用した挨拶
* 基本的な会話処理
* 予定管理

## 今後実装予定の機能

* ユーザー名・設定の保存
* 時刻による挨拶の変化
* 予定管理
* 天気API連携
* 通知機能
* 会話履歴の保存
* KanaとPomeの人格分離
* Kana・Pome・ユーザーによる3者会話
* 音声合成
* 自発的な声かけ

## 開発目的

このプロジェクトは、Pythonやバックエンド開発、API連携、データ保存、AI連携などを学びながら、実際に使用できるアプリケーションへ成長させることを目的としています。
