# KanaAI

KanaAIは、一人暮らしの人に寄り添うAIコンパニオンを目指すプロジェクトです。

## Vision

予定管理や日常会話をするだけではなく、
「おはよう」「行ってらっしゃい」「おかえり」といった何気ない言葉に、
その日の出来事や過去の会話、ユーザーとの関係性を反映できるAIを目指します。

KanaAIでは、単に正しい答えや優しい返答を返すのではなく、
「このAIは今こう思っているんだな」とユーザーが自然に感じられることを重視します。

同じ「おかえり」でも、
いつも通りの日、帰宅が遅かった日、朝からつらそうだった日では、
Kanaの返し方が少しずつ変わります。

将来的には、ユーザーとの記憶を積み重ねながら、
Kana自身にも好みや価値観、感情表現の違いが生まれ、
一人ひとりとの関係によって異なる人格へ成長していくことを目指します。
